Two-to-four option switcher with a pill indicator that slides on the std spring; use for period/order toggles.

```jsx
<SegmentedControl options={['Dia','Semana','Mês']} value={p} onChange={setP} />
<SegmentedControl size="sm" options={[{value:'out',label:'Out'},{value:'nov',label:'Nov'}]} value={m} onChange={setM} />
```
