Circular icon-only button for search, back, add and toolbar actions.

```jsx
<IconButton icon="search" label="Buscar" />
<IconButton icon="chevron-left" variant="plain" label="Voltar" />
<IconButton icon="copy" variant="inverse" size={36} iconSize={18} label="Copiar" />
```

- Press scale .9 (small control), hover/press fill --soft. Always pass a pt-BR label.
