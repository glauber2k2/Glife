# Bíblia v2 — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Levar ao app o protótipo aprovado da Bíblia v2: leitor em Outfit com ajustes e grifos com respiro, início com
busca e registros, e planos de leitura sincronizados com lembrete.

**Architecture:** Regras puras no `packages/domain/src/bible` (busca, registros, cronograma dos planos, repositório
dos planos); a feature `apps/app/src/features/bible` faz telas e dados locais; `links` ganha um watch de todos os
vínculos bíblicos; `today/NoticesSync` agenda os lembretes. Duas tabelas novas (`bible_plans`, `bible_plan_reads`)
com RLS padrão e sync.

**Tech Stack:** Expo SDK 58 + Expo Router, TypeScript, Reanimated, PowerSync (SQLite), Supabase (Postgres), vitest
(+ PGlite), Zod.

**Spec:** `docs/superpowers/specs/2026-11-27-biblia-v2-design.md` (leia junto). Protótipo de referência visual:
`Desktop/Glauber/glife-redesign/biblia/glife-biblia-v2_2026-11-27.html`.

## Global Constraints

- Regras do `AGENTS.md` valem em tudo (rotas finas, features só pelo `index.ts`, `shared/` não importa features,
  domain sem React/Expo e imports relativos com `.ts`, só tokens — nada de hex ou número solto —, `makeStyles`,
  `<Text variant tone>`, componentes de `@/shared/ui`, Lucide 1,5, textos pt-BR, modo escuro, 360 dp).
- Antes de cada commit: `pnpm lint && pnpm typecheck && pnpm test` (na raiz `glife/`). Commits `tipo(biblia): …`,
  e-mail noreply, sem co-autoria.
- Fonte: Outfit em tudo; Literata sai do app.
- Leitor: um versículo por linha; sem modo parágrafo.
- Ajustes: tamanho 15–26 (padrão 19), entrelinhas 1,6–2,4 passo 0,05 (padrão 1,9), letras −2…10 % (padrão 0),
  números dos versículos (padrão ligado).
- Respiro do grifo: `gap = max(0,42 × fontSize, 4)` px entre faixas.
- Tokens novos: `selectionTone` claro `rgba(45,91,255,0.12)` / escuro `rgba(143,167,255,0.20)`; `paper` claro
  `#FFFFFF` / escuro `#0F1219`; `ink` claro `#171B22` / escuro `#E6E9F0`.
- Plano: dia avança pelo calendário; `days` = dias de leitura; pausa empurra dias seguintes; ler adiantado vale;
  recuperar só abre o leitor; sequência só conta leitura até a data do dia.
- Migração nova nunca edita a anterior; `vida_apply_standard`; FK composta; publicação `powersync`; `sync-streams.yaml`.

## Review Focus

1. Tradução importada sem alguns livros/capítulos → a busca ignora os que faltam e não quebra; o leitor mostra o vazio de hoje.
2. Plano que começa no futuro, ou hoje não é dia de leitura → cartão mostra o próximo dia, sem dias perdidos.
3. Dois aparelhos marcam o mesmo capítulo do plano offline → conta uma vez; desmarcar apaga as duas cópias.
4. Preferência de leitura corrompida ou fora da faixa no armazenamento → volta ao padrão sem derrubar o leitor.
5. Busca com só palavras de 1 letra ("o", "e") → nenhum resultado (não "todos os versículos").

Cada item tem teste na tarefa dona (marcados com **[RF n]**).
